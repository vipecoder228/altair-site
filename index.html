Приватность и безопасность

Твои данные — локальные файлы

Память, навыки, история и настройки лежат обычными файлами в твоей папке. Без регистрации, аккаунтов и облаков.

Секреты под замком Windows

API-ключи и токены шифруются через DPAPI (Data Protection API): прочитать их сможет только твой профиль Windows. Если шифрование недоступно — Altair не пишет ключ открытым текстом.

Полный офлайн-режим

С Ollama ни интернет, ни API-ключи не нужны. Лицензия активируется офлайн (подпись RSA-2048), сервер не нужен — онлайн-проверок нет.

Опасные действия — с подтверждением

Закрытие окон, процессы и системные действия требуют твоего «да»: кнопки ✅/❌ в чате.

Вопросы

Нужен ли интернет?

Нет. Подключил Ollama — и ассистент работает полностью офлайн, без интернета и ключей API. Без Ollama — использует любой провайдер, ключи остаются твоими.

Где хранятся мои данные?

Локально, в твоей папке: память, навыки, история, правила и настройки — обычные файлы. Без регистрации, аккаунтов и облаков.

Какой голос будет у ассистента?

Классический Джарвис, GLaDOS, Postal Dude — или собственный голос, клонированный через RVC.

Чем Free отличается от Pro?

Free — чат, голос, память, расписание и базовые пакеты команд. Pro — research-агент, браузер-агент, SSH-доступ и кракер архивов. Ключ Pro активируется офлайн, сброс возвращает Free.

Работает ли с умным домом?

Да: Home Assistant и MQTT — свет, розетки, климат и сцены голосом, например «сцена кино». Управление идёт напрямую, без облака.

Что нужно для установки?

Windows 10 / 11, 64-бит. Остальное поставит установщик — руками ничего не нужно.

  • Интернет — нужен для ИИ и голоса
  • Микрофон — опционально, для голосовых команд
  • FFmpeg — опционально, для лучшего качества записи
  • Python — устанавливается автоматически
Altair не слышит меня

Зайди в Настройки → выбери нужный микрофон → нажми «Проверить микрофон».

Ошибка «Python не найден»

Переустанови Altair и при запросе разреши установку Python.

Ошибка ИИ

Проверь API-ключ в Настройках и убедись, что ключ активен на сайте провайдера.

Предупреждение антивируса

Altair использует системные API для управления звуком и окнами — это может вызывать ложное срабатывание. Добавь папку установки в исключения антивируса.

Хочу другую модель ИИ

В Настройках смени провайдера или введи свой Base URL и модель.
